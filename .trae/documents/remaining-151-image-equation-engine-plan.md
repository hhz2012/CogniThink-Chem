## 一、核心结论（先看这里）

对全部 151 道未解逐题归因后，**绝大多数不是"图像/方程引擎能力缺口"**，而是：

1. **数据缺陷**（答案键垃圾值 / 题面拼接碎片 / 答案错位 / 题面不完整）——约 25 道，归入 `data-defect-register.md`，诚实留 `null`，需数据管道或官方源修复，**不由本轮引擎解决**。
2. **多段填空碎片**（大题某一小问被单独抽成题录，`answer` 是整道大题的复合串）——约 70 道，引擎即使能产出某一子问的正确答案，也面临"复合答案子串匹配 + 子问定位"的假阳性风险，**多数诚实留 `null`**；仅其中"单问、答案干净、产物确定"的方程书写小题可被方程引擎安全覆盖。
3. **选择需化学推理/几何**（graph 流程推断物种、curve 读数+推理、molecule 共平面/红外）——约 30 道，前序 `image-ocr-choice-coverage` 已全量审计：graph/curve/molecule 校验器的机械断言空间已覆盖，剩余均需身份推断或几何，**建求解器会引入假阳性，不建**。
4. **真正可由"图像引擎 + 方程引擎"安全扩展的子集很小**，且每一项都卡在**资产抽取是否可靠**上：
   - 图像侧：晶胞计数（crystal）是唯一机械可判的新资产类型，但当前**无晶胞结构化资产、无 `pdf_images/` 渲染图**，需先建抽取管线；装置图/表格/微观示意均判定为高风险，诚实留空。
   - 方程侧：可扩展一个"反应知识库检索书写器"（reactants → `reactions/*.json` → 配平方程式）+ 若干产物确定的规范模板，覆盖题干干净、反应物锚点齐全、产物无歧义的方程书写小题。

**预期**：在严守 precision=1/harm=0/LOSS=0 的前提下，图像引擎潜在 GAIN 0–4 题（强依赖晶胞资产抽取 spike 能否通过），方程引擎潜在 GAIN 3–8 题。**不为刷覆盖放宽契约**；达不到红线的批次不合并。其余 139+ 题诚实留 `null` 并补登缺陷登记册。

## 三、图像引擎修复方案

### 3.1 候选 A：晶胞资产 + CrystalCellValidator（最高 ROI，但强依赖抽取 spike）

#### 化学上机械可判的断言
晶胞计算的核心是**均摊法**，完全确定：
- 顶点原子 ×1/8、棱上 ×1/4、面心 ×1/2、体内 ×1 → 晶胞原子数 / 化学式；
- 配位数：离某原子最近且等距的原子数（从结构化坐标算距离排序）；
- 密度 ρ = (Z·M)/(N_A·a³)（边长 a 已知时）。
这些不涉及化学推理，**给对结构化坐标就能唯一算对**，符合"不蒙数"。

#### 资产 payload schema（新增 `type=crystal`）
```json
{
  "type": "crystal",
  "source": "pdf_images/pXXX_nYY_0.png",
  "payload": {
    "cellType": "cubic|tetragonal|...",
    "a": 0.5,            // 边长 nm（若题面标注）
    "atoms": [
      {"element": "Ni", "position": "corner|edge|face|body", "wyckoff": "4a", "fracCoords": [0,0,0]},
      {"element": "O",  "position": "face",   "fracCoords": [0.5,0.5,0]}
    ],
    "bonds": []         // 可选
  }
}
```
`position` 字段直接驱动均摊；`fracCoords` 驱动配位数计算。

#### 消费校验器：`CrystalCellValidator`
- 守卫：存在 `type=crystal` 资产 + payload.atoms 非空 + 题干含明确计数/配位数/密度问法（正则锚定，如「晶胞中含有…的个数」「配位数」「密度为」）；否则 `null`。
- 仅在四选项全部可机械判定（choice）或答案为单一数值/化学式（fill）时产出；任一断言无法由坐标算出 → 整题 `null`。
- 输出结论含计算式（如「NiO 晶胞含 Ni²⁺：8×1/8=1、O²⁻：6×1/2=3？→…」），便于审查。

#### 可解的真实题子集（需逐题 spike 验证资产可抽取）
| 题号 | 问法 | 存储 answer | 障碍 |
|------|------|-------------|------|
| pdf-206 | 白锡晶胞原子数 / 体积比 | `(1)4 (2)V2/4V1` | 多段，(1) 可判；需抽晶胞 |
| pdf-222 | P₄ 晶胞密度 | `4.96×10^23/(N_A·a^3)` | 数值匹配风险（子串"4.96"需精确）；需边长 a |
| pdf-170 | NiO 晶胞 Ni²⁺ 个数 | `B`（疑似错位） | **答案疑似错位**，先核键，否则修了也判不对 |
| pdf-178 | Mn₃Sb 配位数 | `C`（疑似错位） | 同上 |
| pdf-498 / 511 | 由化合物结构图推元素（选择 D） | `D` / `D` | **不是晶胞计数**，是元素身份推断 → 不在机械可判域，诚实 `null` |

**预期 GAIN：0–2 题**（pdf-206、222 若资产抽取成功且数值子串匹配通过）；pdf-170/178 需先核键。**不保证有正收益**——若晶胞资产抽取无法达到 100% 准确，整个候选 A 撤回，不勉强。

#### 资产抽取来源（必须先解决）
当前无 `pdf_images/`。候选路径（按可行性排序）：
1. 复用 `pdfs/_extract/vl_cache2/3/` 既有 VL 结果，看是否有晶胞结构的 JSON 描述；若无，
2. 用 `src/CogniThink.TutorBrain.PdfOcrRepair`（已存在的独立 C# 工具，Task 2）渲染源页 + 人工/规则标注少量晶胞为 `position` 标签（**不**批量 VL，避免低质资产）；
3. 每条晶胞资产入库前必须人工核对渲染图，坐标错一条不入库（宁可不解）。

### 3.2 候选 B：官能团填空求解器（依赖分子资产抽取 spike）

- 守卫：分子解析失败、官能团集与答案集合不构成子集关系、题干不问官能团 → `null`。
- **预期 GAIN：0–4 题**，强依赖抽取。抽取失败则撤回。

### 3.3 明确不建（诚实留空，附理由）
- **装置图（apparatus）**：pdf-100/138/406/409/459/540 等。装置正误判断（如"不能达到预期目的"）需要知道每个装置能做什么、连接是否正确——这是化学知识判断，不是从图能机械读出的。强行结构化装置语义会引入假阳性。留 `null`，归缺陷登记 C 类。
- **表格**：pdf-227/262。表格数值应回填 `question` 文本（数据修复），不是引擎消费。且均为多段填空。
- **微观示意图 / 球棍模型**：pdf-188（轨道表示式）、pdf-307 等。轨道/电子云/杂化的可靠判定需 3D 结构，2D 图示不可靠。
- **graph/curve/molecule 既有校验器扩展**：前序已审计无安全可扩展项，不再动。
- **价-类二维图 / 转化关系图**：需物种身份推断，非机械可判（graph 审计已定论）。

## 四、方程引擎修复方案

### 4.1 现状（证据）
方程生成链路（`LlmGatewayService.CallCompile` L635–689）：
`MultiSubCorrectnessSolver → RedoxGatewaySolver → ProductWriterSolver（仅 4 组规则：FeBr₂+Cl₂/NaAlO₂+CO₂/Ca(HCO₃)₂+NaOH/NaCN+CO₂，命中后调 EquationBalancer 配平骨架）→ ConceptVerdictSolver → KnownEquationWriterSolver（仅 2 条硬编码：GaN、Na₂SO₃+SO₂）→ ImpurityTrapSolver → TryJudgeReactionFeasibility → 回退 compiler/Evaluate（占位结论，不被采纳）`。

- `EquationBalancer`（`Chem.Core/Balancing`）**能对给定骨架配平**（唯一正整数解才返回，否则 null），但**不能推断未知产物**。
- 反应知识库 `data/knowledge/reactions/*.json` 共 **244 条**（无机 149 / 有机 51 / 原理 44），schema `{id, name, reactants[], conditions[], products[], equation, ...}`，`ReactionLibrary.FindByReactants` 可按反应物检索。**当前链路未把 KB 用于"书写方程式"**（`ChemicalInferenceService.Evaluate` 只做检索排序输出占位，不产出可采纳的配平方程式）。
- 判分：非 choice 走 `answerKeywords` 子串命中（任一命中即正确，经 `NormalizeChemicalNotation` 规范化）。采纳门要求结论含「离子方程式/化学方程式/具体结论」签名。

### 4.2 候选 C：反应知识库检索书写器 `ReactionKbWriterSolver`

**思路**：对题干明确要求「写出…（离子）方程式」、且反应物锚点可从题干唯一解析的题，在 `reactions/*.json` 中按反应物集合检索；若**唯一命中**且条件（常温/△/通电等）与题干不冲突，则输出该条目的配平方程式（规范化为与评估侧一致的写法）；否则 `null`。

**守卫（precision=1 的根本保证）**：
1. 题干必须含「方程式/方程」锚点；
2. 从题干解析出的反应物集合在 KB 中**恰好 1 条**匹配（>1 或 0 → null，绝不猜）；
3. 产物集与题干明示的产物（若有）不矛盾；
4. 输出方程式经 `NormalizeChemicalNotation` 后必须是存储 `answer`/`answerKeywords` 的子串（探针预校验，不通过的题不纳入该规则）；
5. 不命中返回 `null`，对其余 757−N 题零行为变化（LOSS=0）。

**候选评估（逐题探针，非承诺）**：
| 题号 | 题干要点 | 期望方程 | KB 是否命中 | 风险 |
|------|----------|----------|-------------|------|
| pdf-044 | KHSO₄+Ba(OH)₂ 至中性 / 至 SO₄²⁻ 沉淀完全 | 两条离子方程 | 复分解模板可覆盖 | 产物需看"中性/沉淀完全"条件，方向判定是关键 |
| pdf-084 | 废旧催化剂回收写方程 | 多条 | 需看具体反应物 | 多段，单条可判子集 |
| pdf-133 | MnO₂+4H⁺+2Cl⁻△→Mn²⁺+Cl₂↑ | 制 Cl₂ | KB 有 RX-IN-CL（电解食盐水等，需核实有无 MnO₂ 制 Cl₂） | 若 KB 无则需补模板 |
| pdf-174 | MnO₂ + SO₃²⁻ + 2H⁺ → Mn²⁺ + SO₄²⁻ + H₂O | 干净单方程 | KB 可能无此特定反应 | 需补氧化还原模板（见候选 D） |
| pdf-417 | 加盐酸：H⁺+OH⁻=H₂O；2H⁺+CO₃²⁻=H₂O+CO₂↑ | 两条，干净 | 中和 + 酸+碳酸盐（KB 有） | 需从流程上下文知另一反应物是 OH⁻/CO₃²⁻ |
| pdf-010 | Fe₂O₃+HCl 等（多子问） | 复合答案 | KB 有 Fe₂O₃+HCl | 多段，单条可判子集 |
| pdf-354/355/356/526/527 | 酯化反应（给定反应物） | 酯化方程 | **有机产物推断**（酯化的成键断键），风险高 | 见下，候选 D 之外 |

**预期 GAIN：3–6 题**（pdf-417、010 子集、044 子集、084/133 子集），逐题探针通过才纳入。

### 4.3 候选 D：产物确定型规范模板（窄门控，不推断）

对反应物锚点齐全、产物在高中口径下**唯一确定**的反应，加窄模板（不做通用产物推断，避免 R2 风险）：
- 中和：H⁺ + OH⁻ → H₂O（pdf-417 其一）；
- 酸 + 碳酸盐/碳酸氢盐 → CO₂↑ + H₂O + 盐（pdf-417 其二，KB 已有 RX-IN-NA-009/010）；
- 活泼金属 + 酸 → H₂ + 盐；
- 金属氧化物 + 酸 → 盐 + H₂O（pdf-010 的 Fe₂O₃+HCl，KB 已有 RX-IN-FE-010）；
- 氧化还原：MnO₂ 作氧化剂被还原为 Mn²⁺（pdf-174）——此条需氧化态推断，**风险较高**，仅当题干明示还原产物为 Mn²⁺ 时才命中，否则不纳入。

每条模板：窄门控（反应物全锚定 + 问方程式）+ 产物唯一 + 输出与答案子串预校验。模板命中失败 → `null`。

### 4.4 电极反应式（pdf-304、313 等）——评估后大概率留 null
pdf-304（CO-空气燃料电池，a 极反应 `CO-2e⁻+4OH⁻=CO₃²⁻+2H₂O`）、pdf-313（电解 Na[B(OH)₄]）。电极反应需判断电极极性、介质、放电顺序——是电化学推理，不是机械书写。`reactions-principles.json` 有半反应（`halfReactions`）条目，但"从题干装置图判断哪一极、什么介质"仍需推理。**预期留 `null`**，除非后续有可靠的电化学资产（电极/介质结构化）。

### 4.5 明确不建 / 留 null（方程侧）
- **通用产物推断配平器**：无法保证产物唯一（如酯化的成键位置、氧化还原的多种可能产物），强行推断会假阳性。不建。
- **题干错位题**：pdf-164（期望与题干不符）、pdf-175（问催化剂答案 `[Cu(NH₃)₄]²⁺`，不是方程）、pdf-179（答案 `B` 选择字母，错路由）、pdf-462（AlOOH 不在 KB，LaTeX 串难匹配）——继承 `a_class_reaction_check_fix_plan` 结论，留 `null`。
- **多空复合题**：pdf-010/163 等答案是 `(1)…(2)…` 复合串，引擎产一条子问答案可能误匹配其他子问；仅在"该子问答案唯一且子串不与他子问冲突"时纳入，否则 `null`。
