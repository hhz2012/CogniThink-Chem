# 规格：化学知识问答与统一解题框架体系

## 问题

当前 CogniThink-Chem 系统已具备：
- 11 个题型引擎 + 统一求解器（ProblemSolver）
- Explainer：逐步讲解 + 知识点溯源 + 易错点
- GuideGenerator：4 级苏格拉底式引导（定位题型→回忆知识点→关键思路→具体提示）
- 知识库 50 条（KH-IN/OR/RP/EX/ST/HT）、规则库（rules.json）
- 前端题目浏览 + 讲解/引导面板

**缺口：**
1. 解题框架未显式化——6 步统一解题顺序（审题分类→建立模型→知识检索→规则应用→精确求解→守恒校验）只存在于引擎内部逻辑，未作为学生可感知的引导骨架呈现
2. 知识库不可检索——前端只能浏览题目，无法按关键词/模块搜索知识点，看不到知识点间的前置依赖关系图
3. 无问答能力——学生无法主动提问（如"什么是勒夏特列原理？""苯能使溴水褪色吗？"），系统只能被动解题
4. 知识与规则脱节——知识点的 `rules` 字段和规则库的 `knowledgeId` 字段已存在双向关联，但前端未展示"这个知识点对应哪些规则、这条规则属于哪个知识点"

## 用户

高中学生（自主复习/做题时需要提示、提问、知识溯源）

## 目标

1. **显式化 6 步解题框架**：将统一解题顺序注入引导生成器，每一级引导对应框架的一步，学生能看到"我现在在第几步"
2. **知识库可检索可浏览**：前端新增知识浏览页，支持关键词搜索、按模块筛选、展示前置依赖链
3. **知识问答能力**：前端新增问答面板，学生输入化学问题，系统从知识库+规则库检索匹配条目并给出要点+易错点+关联规则
4. **知识-规则串联**：知识点卡片展示其关联规则；规则可反查所属知识点

## 非目标

- 不引入 LLM/大模型，问答纯基于知识库+规则库的关键词匹配与结构化检索
- 不改动现有 11 个引擎的求解逻辑
- 不新增知识点内容（复用现有 50 条）
- 不实现对话式多轮问答（单轮检索式问答）

## 功能需求

### FR-1：6 步解题框架引导
- GuideGenerator 现有 4 级引导扩展/重构为对应 6 步框架的引导层级
- 每一级引导标题明确标注框架步骤名（审题分类/建立模型/知识检索/规则应用/精确求解/守恒校验）
- 引导内容不含答案（沿用伴思铁律），但每步指向对应的知识点编号
- 前端引导面板按 6 步展示，当前步骤高亮

### FR-2：知识库浏览与检索
- 前端新增"知识库"页面/面板
- 支持关键词搜索（匹配 name/summary/pitfall/textbookRef）
- 支持按模块筛选（Inorganic/Organic/ReactionPrinciples/Experiment/Structure）
- 知识点卡片展示：id、name、module、tier、textbookRef、summary、pitfall、prerequisites、关联规则
- 前置依赖可视化：展示该知识点的 prerequisites 链（可点击跳转）

### FR-3：知识问答
- 前端新增问答输入框
- 后端 QAService 接收问题文本，执行：
  1. 关键词提取（中文分词简化版：按字符 n-gram + 关键词词典匹配）
  2. 在知识库 name/summary/pitfall 中检索匹配条目
  3. 在规则库 name/conclusion.display 中检索匹配规则
  4. 汇总返回：匹配的知识点（要点+易错点）+ 匹配的规则（display）
- 无匹配时返回"未找到相关知识点，请尝试其他关键词"
- 回答中所有知识点可点击跳转到知识浏览页对应卡片

### FR-4：知识-规则串联
- 知识点卡片显示其 `rules` 字段关联的规则列表（规则 id + name + display）
- 规则可反查：点击规则显示其 `knowledgeId` 所属知识点
- 引导/讲解中的知识点引用可展开查看关联规则

## 非功能需求

- 问答响应 < 200ms（纯本地检索，无网络调用）
- 前端纯静态，不新增依赖
- 后端导出命令 `--export-web` 需同时导出知识库+规则库供前端使用
- 现有 726 个测试必须全绿
- 所有新增后端代码需配套单元测试

## 约束与依赖

- 知识库结构（knowledge.json）不变，复用现有字段
- 规则库结构（rules.json）不变，复用 `knowledgeId` 关联
- 前端框架不变（纯原生 JS/CSS）
- 问答不使用 LLM，纯关键词匹配+结构化检索

## 验收标准

### AC-1（rule）：6 步框架引导
GuideGenerator 输出的 Guide.Levels 中，每级 Title 包含 6 步框架关键词之一（审题分类/建立模型/知识检索/规则应用/精确求解/守恒校验），且引导文本不含答案方程式/数值结论。

### AC-2（rule）：知识库导出
`--export-web` 后 `web/data/knowledge.json` 存在且包含全部 50 条知识点 + 全部规则，每条知识点含 `rules` 关联的规则详情。

### AC-3（rule）：知识检索页面
前端知识浏览页可搜索"勒夏特列"并返回 KH-RP-03，可按模块筛选只显示 Organic 类知识点。

### AC-4（rule）：知识问答
输入"苯能使溴水褪色吗"返回 KH-OR-01 知识点（含 pitfall"苯不能使溴水因反应褪色"）；输入"电子守恒"返回 CONS-ELEC-001 规则。

### AC-5（rule）：知识-规则串联
知识点 KH-RP-03 的卡片显示其关联规则 EQ-001、EQ-002；规则 EQ-001 可反查到所属知识点 KH-RP-03。

### AC-6（rule）：回归测试
`dotnet test` 全部通过，且新增的 QAService / FrameworkGuide 测试通过。
